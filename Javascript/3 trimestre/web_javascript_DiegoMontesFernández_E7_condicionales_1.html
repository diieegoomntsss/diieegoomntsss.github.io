Ejercicio 07 — Introducción de datos y toma de decisiones

Este programa pregunta primero al usuario si quiere jugar. Si responde afirmativamente, le pedirá que escriba el nombre de una fruta y le mostrará el precio según la fruta indicada. Luego hace una segunda pregunta sobre si desea seguir consultando y finaliza con un mensaje adecuado. Si la respuesta inicial es negativa o incorrecta, el programa avisa o termina según corresponda.
